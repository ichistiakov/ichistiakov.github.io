Картинки в постах вставляются тремя способами. Первый — обычный markdown: положите файл в папку `img/` рядом с постом и сошлитесь на него. Заголовок в кавычках станет подписью:

![Абстрактная композиция](img/kartina-odin.jpg "Обычная markdown-картинка: Hugo сам сожмёт её до нужного размера")

Второй способ — шорткод `figimg`, когда нужно управление размером. Класс `is-half` делает картинку в половину колонки:

{{< figimg src="img/kartina-dva.jpg" caption="Шорткод figimg с классом is-half — фото в пол-колонки, по центру" class="is-half" >}}

Третий — карусель для серии картинок. Каждая строка внутри шорткода — отдельный слайд со своей подписью, листается стрелками, свайпом и клавиатурой:

{{< carousel >}}
![Слайд первый](img/kartina-odin.jpg "Первый слайд карусели")
![Слайд второй](img/kartina-dva.jpg "Второй слайд — подпись меняется под картинкой")
![Слайд третий](img/kartina-tri.jpg "Третий слайд. Без JS все картинки просто идут подряд")
{{< /carousel >}}

Обложка поста — файл `cover.jpg` рядом с `index.md`: она автоматически появляется в списке блога и в начале поста. Не хотите обложку внутри поста — добавьте `hideCover: true` во frontmatter.
