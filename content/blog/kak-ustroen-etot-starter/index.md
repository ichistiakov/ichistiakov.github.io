Этот сайт собран на <a href="https://gohugo.io/" target="_blank" rel="noopener">Hugo</a> — генераторе статических сайтов. Вы пишете посты в markdown, Hugo превращает их в готовый HTML, который можно положить на любой хостинг: от GitHub Pages до собственного сервера.

## Где что лежит

- `hugo.toml` — имя, домен, меню. Начните отсюда.
- `data/site.yaml` — ссылки, подвал, список проектов.
- `content/` — страницы сайта и посты блога.
- `themes/` — четыре темы оформления; активная выбирается одной строкой в `hugo.toml`.

## Как переключить тему

В `hugo.toml` поменяйте строку `theme = "meridian"` на любую из: `manuscript`, `signal`, `midnight`. Посмотреть тему, не меняя конфиг:

```bash
hugo server --theme midnight
```

А чтобы собрать все четыре сразу и сравнить — `./scripts/preview-all.sh`.

## Как добавить пост

Каждый пост — папка в `content/blog/` с файлом `index.md` внутри. Рядом с ним живут обложка `cover.jpg` и картинки в `img/`. Новый пост из шаблона:

```bash
hugo new content --kind blog blog/moy-pervyy-post
```

Остальное — в README и AGENTS.md. Второй файл написан специально для AI-агента: отдайте ему репозиторий, и он разберётся сам.
