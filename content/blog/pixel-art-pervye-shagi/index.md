Заметки о том, с чего начать рисовать пиксель-арт для веба.

## Инструменты

- **Aseprite** (~20 €) — стандарт индустрии: анимация, тайлы, удобные палитры.
- **Piskel** — бесплатный, работает в браузере, для первых спрайтов хватает с головой.

## Основные правила

1. Маленький холст: 16×16 или 32×32 на спрайт — ограничение и есть стиль.
2. Ограниченная палитра: 8–16 цветов, тёплые тона держат настроение.
3. В CSS — `image-rendering: pixelated`, иначе браузер размоет пиксели при масштабировании.
